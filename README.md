# Q-Molecule
## Qiskit Fall Fest 2026 - Phase 1, C1: Molecular Ground-State Energy (H2)

Q-Molecule investigates the H2 ground-state energy using a precomputed four-qubit Hamiltonian, a variational quantum eigensolver (VQE), architecture-aware circuit compilation, and a separate illustrative noise experiment.

**Scope:** Processor A and Processor B only. All reported results are from classical simulation and compilation. No physical quantum processor was accessed.

## 1. Scientific Method

- Molecule: H2
- Bond distance: 0.735 Angstrom
- Basis-set label: STO-3G
- Mapping: Jordan-Wigner
- Hamiltonian: 4 qubits and 15 Pauli terms
- Solver: hardware-efficient four-qubit ring ansatz
- Optimizer: L-BFGS-B
- Random seeds: 42, 1, 2

The Hamiltonian coefficients were transcribed from a Qiskit Nature mapping tutorial and rounded to eight decimal places. Molecular integrals were not generated locally using PySCF. The exact reference energy was calculated by diagonalizing the same stored Hamiltonian, so it validates the optimizer against that operator rather than independently validating a molecular-integral calculation.

## 5. Illustrative Noise Experiment

| Two-qubit depolarizing probability | 0.01 |
| Readout-error probability | 0.02 |

| Simulator seeds | 42, 123, 2026 |

| Metric | Processor A | Processor B |
|---|---:|---:|

Only three runs were performed per configuration. These estimates illustrate behavior under the assumed noise model; they are not predictions of real-device performance.

## 7. Installation and Reproduction

Use Python 3.12. From the repository root in Windows PowerShell, install the dependencies:

```powershell
python -m pip install -r requirements.txt
```

Regenerate processor configurations:

```powershell
python processors\processor_A.py
python processors\processor_B.py
```

Run the H2 solver, compilation benchmark, and noise experiment:

```powershell
python src\h2_solver.py
python src\benchmark_processors.py
python src\noise_experiment.py
```

Open `main.ipynb` in VS Code, select the project's Python environment, and run the notebook cells from top to bottom.

Generated tables are saved under `results/tables/`; figures are saved under `results/figures/`.

## 8. Limitations

1. The Hamiltonian is precomputed and rounded; molecular integrals are not generated locally.
2. The ansatz is hardware-efficient, not UCCSD.
3. The exact reference is calculated from the same stored Hamiltonian.
4. Processor coupling graphs and port assignments are participant-designed assumptions.
5. The noise probabilities are illustrative, not official processor specifications.
6. All results are from simulation and compilation, not physical quantum hardware.
7. Compilation metrics depend on circuit choice, initial layout, transpiler settings and connectivity.
8. The reported three-run noise statistics are limited estimates of variability.

## 10. Conclusion

The VQE optimizer closely reproduces the exact ground-state energy of the stored four-qubit H2 Hamiltonian. The compilation benchmarks demonstrate different routing overhead for the chosen Processor A and Processor B graphs. The noise experiment illustrates sensitivity to an assumed noise model.

These findings apply only to the implemented Hamiltonian, selected circuits, participant-designed graphs and simulation settings. They do not independently validate molecular-integral generation or demonstrate physical-hardware performance.
